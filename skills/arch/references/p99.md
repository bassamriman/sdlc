# p99 checklist: cause to fix

- Fan-out amplification: hedged or tied requests after the p95 delay, partial results, fewer hops.
- Retries and timeouts: propagate deadlines, set each timeout from the callee's measured p99 (not a round number), use a retry budget, do not retry at every layer; circuit-break and serve stale or degraded instead of waiting on a slow dependency.
- Slow replica or shard: outlier ejection (drop a server whose latency spikes, probe before readmitting), many small partitions so load moves off a slow shard.
- Head-of-line blocking: separate pools per workload class, bounded queues, shed load.
- Chatty or N+1 calls: batch, dataloader, join, prefetch (`select_related`/`prefetch_related`).
- Cache stampedes: request coalescing, TTL jitter, stale-while-revalidate, negative caching.
- Connection pools: size with Little's law, keepalive, watch pool wait time.
- GC and allocation: cut garbage, avoid boxing and huge heaps, tune the collector, read pause logs.
- Lock contention: smaller critical sections, sharded locks, immutable snapshots.
- Query plans: `EXPLAIN ANALYZE`, missing or non-selective indexes, sorts spilling to disk, long transactions.
- Pagination: keyset not OFFSET, capped page size, no unbounded result sets.
- Sync work on the hot path: move non-critical work behind a queue or outbox.
- Background interference: compaction, batch jobs, noisy neighbours; schedule off-peak.
- Cold starts and JIT warmup: pre-warm, health-gate before taking traffic.
- Measure with histograms per dependency, never averages; avoid coordinated omission in load tests.
