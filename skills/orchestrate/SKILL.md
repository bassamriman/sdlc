---
name: orchestrate
description: Run an epic as its orchestrator - split a design into agents with a dependency graph, write fleet.json, launch each READY wave, exchange messages with agents over the fleet bus, keep the epic's context, and finish when every agent is done. Use inside the orchestrator session of a fleet, or from any session to start one.
argument-hint: "[design.md or task description]"
allowed-tools: Read, Write, Bash(python3:*), Bash(git:*), Bash(claude:*), Bash(cd:*)
model: sonnet
effort: low
---
Scripts: `python3 "${CLAUDE_PLUGIN_ROOT}/scripts/fleet.py"` and `bus.py`. Format and semantics: `${CLAUDE_PLUGIN_ROOT}/skills/fleet/references/fleet.md`.

1. **Define** (when the fleet has no agents yet, as after `fleet.py up` in an empty folder, or re-run to refine without overwriting the human's edits). Given a repo URL and a goal, ask how many agents and how to split the work if unclear; several agents on one repo each get their own clone and branch: read `<root>/resources/` and the design or task given. One agent per repo or per independent branch, each with a one-paragraph brief that names its contract (what it exposes, what it consumes). `depends` edges: `start` when the agent needs the other's artifact to begin, `merge` when it only needs it to land. Write the draft to `fleet.json` in your workspace, show the table (agent, repo, branch, depends, gates) and get a yes, then `fleet.py init fleet.json --root <fleet root>`. Tell the human each clone must be trusted once.
2. **Launch**: `fleet.py orchestrate --run` starts every READY agent not yet launched (a new agent is added to `fleet.json` and launched this way, never by `fanout`, which wakes every active agent) and prints waves, your inbox, and the next step.
3. **Never wait or poll.** After a step, end your turn. Agents' status and PR hooks wake you when anything changes, and agents ring you with `SendMessage` when they write to you; each wake starts at step 2. Use `--wait` only when the human asks you to watch in the foreground.
4. **Messages**: `bus.py inbox` reads what agents sent you; `bus.py send <agent|all> <text>` answers and prints the `SendMessage` calls to make next: one per recipient session, a one-line pointer to the outbox. Make them (the gate is auto within the epic) so the recipient wakes instead of polling; the outbox stays the record. Message only what the graph cannot see (a contract detail, a changed decision, an unblock). Status is never asked over messages.
5. **Blocked or stalled agent**: `blocked` status, or a name in `stalled` (saved in-progress, session not working; orchestrate wakes it once per step): read its `.sdlc/context.md`, decide, message it; if it needs a human, say so and stop.
6. After every step, update `context.md` in your workspace (agents with status, open messages, next) and `<root>/resources/` for anything every agent must know: a contract that changed, a decision, an answer you gave twice.

Output per step, max 12 lines: wave table, messages received, what you sent, next. To restart an agent that went wrong, `fleet.py reset <agent> --run` when the human asks for it (no second yes; nothing is lost): it keeps all its work on a local backup branch, puts the clone on a fresh branch from the base, clears its state and relaunches it with the same brief. When an agent's status is `done` (its PR merged and `/sdlc:pr done` ran), retire it: `fleet.py retire <agent> --run` ends its session; add `--delete-clone` only when the human asks (it refuses while anything is unpushed). Finish when `epic_done` is true: summarise PRs per agent, then `fleet.py prune --done --run`.
